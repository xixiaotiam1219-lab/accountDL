# 用户协议

欢迎您使用“记得订阅”应用程序（以下简称“本软件”）。在本软件中，我们将为您提供订阅服务管理、提醒及分析功能。在您使用本软件前，请务必仔细阅读并理解本《用户协议》（以下简称“本协议”）。

## 1. 服务内容

本软件为您提供订阅项目的记录、自动续费提醒、支出统计服务。本软件采用纯本地运行模式，所有数据均存储在您的设备本地。

## 2. 数据安全与备份

由于本软件不提供云端备份功能，您的所有订阅数据仅保存在当前设备中。为防止数据丢失，建议您定期使用软件提供的“备份数据 (.json)”或“导出数据 (.csv)”功能将数据保存到安全位置。

## 3. 用户行为规范

您承诺合法、合理地地使用本软件。不得利用本软件从事任何违法活动，包括但不限于侵犯他人知识产权、传播不良信息等。

## 4. 隐私保护

我们高度重视您的隐私。由于数据存储在本地，我们不会在服务器端收集您的订阅明细。有关更详细的信息，请参阅我们的《隐私政策》。
